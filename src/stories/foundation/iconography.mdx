# Iconography guide

Our design system includes over **500 custom duotone icons** available through `@/components/icons`. These are designed to be clear, consistent, and scalable.

## Icon categories

The icons are logically grouped into the following categories to cover various use cases:

- **Arrows:** For directional navigation and flow (e.g., `IconArrowRight`, `IconTrendUp`).
- **Chevrons:** For dropdowns, accordions, and subtle directional cues.
- **Alignment:** For text and layout alignment controls.
- **Layout and panels:** For representing UI structure like windows, sidebars, and grid elements.
- **Typography and text:** For rich text editor controls and formatting.
- **Shapes and design:** For graphic design tools, layers, and geometric shapes.
- **Files and folders:** For document management and file types.
- **Media and audio:** For playback controls, volume, cameras, and multimedia.
- **Waves and signals:** For network strength, broadcasting, and abstract waveforms.
- **Communication:** For messaging, emails, notifications, and sharing.
- **Phone:** For call states and mobile interactions.
- **Devices:** For representing hardware like laptops, phones, servers, and printers.
- **Input and cursor:** For pointer states, touch gestures, and interactions.

## Usage

- **Importing:** Always import icons from the centralized components folder (e.g., `import { IconArrowRight } from '@/components/icons'`).
- **Sizing:** Use standard sizing classes like `size-icon-base`, `size-icon-lg`, or `size-icon-3xl` to ensure alignment with typography.
