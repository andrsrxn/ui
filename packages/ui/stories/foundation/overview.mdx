The design system has been created because of the need of a solid UI foundation for starting new projects. It's inspired in [Atlassian Design](https://atlassian.design), [Primer Design System](https://primer.style) (Github) and [Base Web](https://base.uber.com) (Uber), combining their best practices, features and design patterns.

The porpuse is to make as fast as possible to start a project with a solid UI foundation, backed by a full design system documentation.

It is correct to reference `andrsrxn/ui` as "the design system" or "the component library". Do not reference it as "the ui", "andrsrxn-ui", "ANDRSRXN" or similar.

## Installation

The script will install a dependency in your project.

```bash
  pnpm add @andrsrxn/ui -E
```

## Usage

```tsx
import { Button } from '@andrsrxn/ui/button'

function ButtonDemo() {
  return (
    <div className='flex items-center gap-2'>
      <Button variant='primary'>Primary</Button>
      <Button variant='secondary'>Secondary</Button>
    </div>
  )
}
```
